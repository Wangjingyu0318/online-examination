问题分析报告 — 题库管理CSV上传功能
============================================================

问题现象：题库管理页面点击"上传题目"，选择CSV文件后，无法将题目真正导入系统。

============================================================
问题一（核心问题）：前端确认导入时数据字段名错误
============================================================
文件位置：templates/admin/questions.html 第718行

原代码：
    body: JSON.stringify({ questions: uploadedData.questions })

原因说明：
后端 /api/admin/questions/upload 接口返回的预览数据中，题目列表字段名是 rows（前20条预览），
而不是 questions。因此 uploadedData.questions 的值为 undefined，
发送给后端 confirm 接口的 questions 数组为空，后端直接返回"没有可导入的题目"。

后端返回结构（routes/admin.py 第237-245行）：
    {
        code: 0,
        data: {
            headers: [...],
            rows: [...],       // 预览数据，字段名是 rows
            stats: {...},
            total: N
        }
    }

============================================================
问题二：后端 confirm 接口逻辑设计错误
============================================================
文件位置：routes/admin.py 第255-329行 confirm_import 函数

原因说明：
1. upload_questions 接口（第186行）已经把完整的CSV解析结果存入了全局变量 _upload_cache（第235行）
2. 但 confirm_import 接口却从请求体中读取 questions 数据（第264行），而没有使用 _upload_cache
3. 导致即使前端字段修好了，也只能导入前端传过来的前20条预览数据，而不是完整的CSV全部数据

正确逻辑应该是：
- 上传阶段：解析CSV → 完整数据存缓存 → 返回前20条给前端预览
- 确认阶段：直接从缓存 _upload_cache 读取全部数据 → 写入数据库

============================================================
问题三：confirm_import 函数缺少 pandas 导入
============================================================
文件位置：routes/admin.py 第301、303、305、307、309、311、313行

原代码：
    if '默认分值' not in q or pd.isna(q.get('默认分值')):
    ...（多处使用 pd.isna）

原因说明：
confirm_import 函数内使用了 pd.isna() 来判断空值，但 admin.py 文件顶部（第1-3行）
只导入了 flask、json、os，没有导入 pandas。
虽然 upload_questions 函数内部有 import pandas as pd（第189行），
但那是函数内局部导入，confirm_import 中无法访问，运行时会报 NameError: name 'pd' is not defined。

============================================================
问题四（补充）：上传解析失败会导致确认按钮不显示
============================================================
文件位置：templates/admin/questions.html 第405、664行

原因说明：
"✅ 确认导入"按钮默认带有 hidden 类（第405行），只有上传解析成功后才会显示（第664行）。
如果用户选择CSV文件后解析失败（比如缺少pandas依赖、CSV格式错误、缺少必要列），
按钮会一直隐藏，用户看不到"确定键"，表现为"选了文件但没反应"。

常见解析失败原因：
1. 环境未安装 pandas 库（upload接口第189行 import pandas as pd 会失败）
2. CSV文件编码不是 UTF-8
3. CSV缺少必要列：题目编号、题型、题干、正确答案、默认分值

============================================================
修复建议汇总
============================================================
1. 前端 questions.html 第718行：uploadedData.questions → uploadedData.rows
   （但这样只能导入20条，治标不治本）

2. 后端 confirm_import 函数：改为直接读取全局 _upload_cache 中的完整数据导入，
   不再依赖前端传过来的预览数据。

3. admin.py 顶部或 confirm_import 函数内添加：import pandas as pd

4. 检查运行环境是否安装了 pandas：pip install pandas
